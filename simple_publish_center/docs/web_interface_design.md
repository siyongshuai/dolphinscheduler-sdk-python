## 概述

本文档描述了工作流管理系统的Web界面设计，包括各个页面的布局、功能和交互方式。该系统旨在提供一个直观、高效的界面，使用户能够方便地创建、编辑、管理和部署工作流。

## 页面设计

### 工作流列表页面

**功能**：显示所有工作流，支持搜索、筛选、创建新工作流

**UI布局**：
```
+--------------------------------------------------------------+
| 工作流管理系统                               用户名 | 退出登录 |
+--------------------------------------------------------------+
| [新建工作流] [导入] [批量操作]       搜索框 [高级筛选]        |
+--------------------------------------------------------------+
| □ | 工作流名称 | 创建时间  | 最后修改时间 | 状态   | 操作     |
+--------------------------------------------------------------+
| □ | 测试工作流1| 2025-04-01| 2025-04-10  | 已部署 | 编辑 更多▼|
| □ | 测试工作流2| 2025-04-02| 2025-04-09  | 草稿   | 编辑 更多▼|
| □ | 测试工作流3| 2025-04-03| 2025-04-08  | 已部署 | 编辑 更多▼|
+--------------------------------------------------------------+
|                         分页控件                             |
+--------------------------------------------------------------+
```

**功能点**：
- 工作流列表展示：名称、创建时间、修改时间、状态等
- 搜索和筛选：支持按名称搜索、按状态/时间范围筛选
- 操作按钮：编辑、删除、部署、导出、复制等
- 批量操作：批量删除、批量部署、批量导出等
- 创建新工作流：点击进入工作流编辑页面

## 交互流程

### 创建工作流流程

1. 用户进入工作流列表页面
2. 点击"新建工作流"按钮
3. 进入工作流编辑页面
4. 设置工作流名称和描述
5. 从工具栏拖拽节点到画布
6. 配置各节点的属性
7. 连接节点形成完整工作流
8. 点击"保存"保存工作流
9. 点击"部署"将工作流部署到执行环境

### 批量部署流程

1. 用户进入批量部署页面
2. 点击"下载模板"获取Excel模板
3. 填写模板中的工作流配置信息
4. 上传填写好的Excel文件
5. 系统解析并预览工作流配置
6. 用户点击"全部验证"进行数据验证
7. 验证通过后，点击"全部部署"进行批量部署
8. 系统显示部署结果

### 脚本管理流程

1. 用户进入脚本管理页面
2. 点击"新建脚本"按钮
3. 填写脚本名称和选择脚本类型
4. 在代码编辑器中编写脚本代码
5. 定义脚本的输入参数
6. 点击"测试"按钮测试脚本
7. 测试通过后，点击"保存"按钮保存脚本
8. 脚本可在工作流编辑中被引用

## API集成

### 前端API调用

前端界面将通过RESTful API与后端服务进行交互。主要API集成点包括：

1. **用户认证集成**
   - 登录页面调用 `POST /api/v1/auth/login` 进行用户认证
   - 使用JWT令牌进行后续请求的身份验证
   - 令牌过期时自动调用 `POST /api/v1/auth/refresh` 刷新访问令牌

2. **工作流管理集成**
   - 工作流列表页面调用 `GET /api/v1/workflows` 获取工作流列表
   - 工作流编辑页面调用 `POST /api/v1/workflows` 创建新工作流
   - 工作流详情查看调用 `GET /api/v1/workflows/{workflowId}` 获取工作流详情
   - 工作流更新操作调用 `PUT /api/v1/workflows/{workflowId}` 更新工作流

3. **脚本管理集成**
   - 脚本列表页面调用 `GET /api/v1/scripts` 获取脚本列表
   - 脚本上传功能调用 `POST /api/v1/scripts` 上传脚本
   - 脚本详情查看调用 `GET /api/v1/scripts/{scriptId}` 获取脚本详情
   - 脚本更新操作调用 `PUT /api/v1/scripts/{scriptId}` 更新脚本

4. **执行实例监控集成**
   - 执行实例列表页面调用 `GET /api/v1/instances` 获取执行实例列表
   - 执行实例详情页面调用 `GET /api/v1/instances/{instanceId}` 获取执行实例详情
   - 节点执行详情查看调用 `GET /api/v1/instances/{instanceId}/nodes/{nodeId}` 获取节点执行详情

### 数据交互模型

前端和后端之间的数据交互采用以下模型：

1. **请求格式**
   - HTTP请求方法：GET、POST、PUT、DELETE
   - Content-Type: application/json 或 multipart/form-data（文件上传）
   - 认证头：Authorization: Bearer {token}

2. **响应格式**
   ```json
   {
     "code": 200,        // 状态码
     "message": "成功",   // 消息
     "data": {}          // 数据对象
   }
   ```

3. **错误处理**
   - 前端统一错误处理中间件
   - 根据错误代码显示友好的错误提示
   - 认证失败时自动跳转到登录页面
   - 服务器错误时提供重试选项

4. **数据缓存**
   - 使用浏览器本地存储缓存不常变化的数据
   - 频繁访问的数据（如工作流列表）采用前端缓存策略
   - 敏感数据不进行本地缓存

## 技术栈

### 前端
- 框架：Vue.js 3
- UI库：Element Plus
- 工作流设计器：X6（图形库）
- 代码编辑器：Monaco Editor

### 后端
- 框架：FastAPI
- 数据库：PostgreSQL
- 工作流引擎：Apache DolphinScheduler API

### 部署
- 容器化：Docker
- 容器编排：Kubernetes (可选)
- CI/CD：GitHub Actions
