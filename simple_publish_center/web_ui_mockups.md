# Web界面模型示例

## 界面模型与交互流程

以下是Web界面的主要页面模型示例和用户交互流程说明。

## 1. 工作流列表页面

```
┌─────────────────────────────────────────────────────────────────────┐
│ 工作流管理                                       + 新建工作流  部署全部 │
├─────────────────────────────────────────────────────────────────────┤
│ 🔍 搜索...          状态筛选 ▼                                        │
├─────────────────────────────────────────────────────────────────────┤
│ 名称 ▲         │ 描述            │ 状态   │ 更新时间      │ 操作       │
├─────────────────────────────────────────────────────────────────────┤
│ data_process_ │ 区域A数据处理工作流 │ 已部署 │ 2025-04-10   │ 编辑 删除   │
│ region_a      │                  │       │              │ 部署 查看   │
├─────────────────────────────────────────────────────────────────────┤
│ data_process_ │ 区域B数据处理工作流 │ 未部署 │ 2025-04-09   │ 编辑 删除   │
│ region_b      │                  │       │              │ 部署 查看   │
├─────────────────────────────────────────────────────────────────────┤
│ data_process_ │ 区域C数据处理工作流 │ 部署   │ 2025-04-08   │ 编辑 删除   │
│ region_c      │                  │ 失败   │              │ 部署 查看   │
├─────────────────────────────────────────────────────────────────────┤
│                                                 1-3 of 3  < 1 >     │
└─────────────────────────────────────────────────────────────────────┘
```

**交互说明**:
- 点击"+ 新建工作流"按钮进入工作流创建页面
- 点击"部署全部"按钮进入批量部署页面
- 点击表格中的"编辑"按钮进入工作流编辑页面
- 点击表格中的"部署"按钮进行单个工作流部署
- 点击表格中的"查看"按钮查看工作流配置和脚本详情
- 表格支持按列排序和多条件筛选

## 2. 工作流编辑页面

```
┌─────────────────────────────────────────────────────────────────────┐
│ 编辑工作流                                           保存  取消  部署   │
├─────────────────────────────────────────────────────────────────────┤
│ 基本信息                                                             │
├─────────────────────────────────────────────────────────────────────┤
│ 工作流名称*: [data_process_region_a                               ]  │
│ 工作流描述 : [区域A数据处理工作流                                    ]  │
│ 任务ID*   : [001                                                  ]  │
├─────────────────────────────────────────────────────────────────────┤
│ 依赖信息                                                             │
├─────────────────────────────────────────────────────────────────────┤
│ 依赖项目*  : [base_project                                         ]  │
│ 依赖工作流*: [data_collect                                         ]  │
│ 依赖任务*  : [collect_complete                                     ]  │
├─────────────────────────────────────────────────────────────────────┤
│ Shell命令内容*                                       检查语法  预览效果 │
├─────────────────────────────────────────────────────────────────────┤
│ #!/bin/bash                                                         │
│ echo "开始处理区域A数据"                                              │
│ date                                                                │
│ # 区域A特定处理逻辑                                                   │
│ echo "区域A数据处理完成"                                              │
│                                                                     │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

**交互说明**:
- 所有带*的字段为必填项
- "检查语法"按钮对Shell命令进行语法检查
- "预览效果"按钮显示工作流的最终YAML表示
- "保存"按钮保存配置但不部署
- "部署"按钮保存配置并立即部署工作流

## 3. 模板管理页面

```
┌─────────────────────────────────────────────────────────────────────┐
│ 模板管理                                                   保存  重置 │
├─────────────────────────────────────────────────────────────────────┤
│ 工作流模板                                                 解析  预览 │
├─────────────────────────────────────────────────────────────────────┤
│ workflow:                                                           │
│   name: "${workflow_name}"                                          │
│   description: "${workflow_description}"                            │
│   release_state: "online"                                           │
│                                                                     │
│ tasks:                                                              │
│   - name: "dependent_${task_id}"                                    │
│     task_type: Dependent                                            │
│     dependent_parameters:                                           │
│       - project_name: "${dependent_project}"                        │
│         workflow_name: "${dependent_workflow}"                      │
│         dependent_mode: "task_dependent"                            │
│         dependent_task_name: "${dependent_task}"                    │
│         dependent_result: "success"                                 │
│                                                                     │
│   - name: "shell_${task_id}"                                        │
│     task_type: Shell                                                │
│     deps: ["dependent_${task_id}"]                                  │
│     command: "${shell_command}"                                     │
└─────────────────────────────────────────────────────────────────────┘
```

**交互说明**:
- "解析"按钮检查模板语法和变量引用
- "预览"按钮使用示例数据显示渲染后的模板
- "保存"按钮保存模板配置
- "重置"按钮恢复默认模板

## 4. 批量部署页面

```
┌─────────────────────────────────────────────────────────────────────┐
│ 批量部署                                          仅生成配置  开始部署 │
├─────────────────────────────────────────────────────────────────────┤
│ 选择工作流                                                   全选     │
├─────────────────────────────────────────────────────────────────────┤
│ [✓] data_process_region_a                                           │
│ [✓] data_process_region_b                                           │
│ [ ] data_process_region_c                                           │
├─────────────────────────────────────────────────────────────────────┤
│ 部署配置                                                             │
├─────────────────────────────────────────────────────────────────────┤
│ [✓] 覆盖已存在的工作流                                                │
│ [ ] 在部署前验证脚本语法                                               │
│ [ ] 同步发布模式(等待API返回)                                         │
├─────────────────────────────────────────────────────────────────────┤
│ 部署状态                                                             │
├─────────────────────────────────────────────────────────────────────┤
│ 工作流: 0/0 | 部署成功: 0 | 部署失败: 0                                │
└─────────────────────────────────────────────────────────────────────┘
```

**交互说明**:
- 选择要部署的工作流(可多选)
- 配置部署选项
- "仅生成配置"按钮只生成YAML配置文件和脚本，不实际部署
- "开始部署"按钮执行部署过程
- 部署状态区域实时更新部署进度和结果

- 显示提示信息，提醒用户脚本修改后需要重新部署相关工作流

## 用户交互流程

1. **创建新工作流流程**:
   ```
   工作流列表页面 --> 点击"新建工作流" --> 工作流编辑页面 --> 
   填写配置信息 --> 编写Shell命令 --> 点击"保存" --> 
   返回工作流列表页面(显示新工作流)
   ```

2. **部署工作流流程**:
   ```
   工作流列表页面 --> 选择工作流 --> 点击"部署全部" --> 
   批量部署页面 --> 配置部署选项 --> 点击"开始部署" --> 
   查看部署状态 --> 完成后返回工作流列表页面(更新状态)
   ```

3. **编辑脚本流程**:
   ```
   脚本管理页面 --> 找到目标脚本 --> 点击"编辑" --> 
   脚本编辑对话框 --> 修改脚本内容 --> 点击"保存" --> 
   返回脚本管理页面 --> 提示"需要重新部署相关工作流"
   ```

4. **修改模板流程**:
   ```
   模板管理页面 --> 编辑模板内容 --> 点击"解析" --> 
   修复潜在问题 --> 点击"预览" --> 确认效果 --> 
   点击"保存" --> 提示"需要重新部署工作流以应用新模板"
   ```
